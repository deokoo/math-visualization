# 等离子体状态智能调节 · LSTM + EKF 融合

面向离子束线设备的等离子体状态智能调节方案可视化：1080×1350 竖屏、30fps、70 秒、暗色底、公式全程固定只动参数与动画。是「七个偏微分方程」「混沌与动力系统」仪表盘的工程主题姊妹篇——把一套 LSTM 与 EKF 融合的电子密度闭环调节链路做成八格「现场仿真」仪表盘。所有数据由 numpy 现场求解生成（含真实 EKF 递推、LSTM 门控前馈、加权融合、二阶闭环控制），无预渲染路径、无 LaTeX。

## 技术要点

- **无 Manim、无 LaTeX**：逐帧 numpy 求解 + PIL 绘制，经 ffmpeg rawvideo 管道直接编码 H.264。公式用 matplotlib mathtext 预渲染成透明 PNG（`formulas/`），首次运行自动生成。
- **真实递推**：EKF 为标量状态协方差预测-更新（含 Kalman 增益与 2σ 带）；LSTM 为门控前馈近似；融合权重按两路误差动态分配；闭环为二阶状态空间（比例-微分控制 + 两次高斯扰动）。
- **预测扇形坑**：初版预测曲线用了未来真值而扇形中心用起点固定值，两者基准不一致导致金线画在扇形下方。改为预测曲线从历史末端平滑延伸、沿真值未来走势、并收在扇形区内。
- **数组对齐坑**：仿真步数 NS 必须等于总帧数（70×30=2100），否则后段帧索引越界。
- **画幅**：全系列统一 1080×1350（4:5）竖屏。编码 H.264 yuv420p + AAC。
