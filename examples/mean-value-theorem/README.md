# 拉格朗日中值定理（Lagrange Mean Value Theorem）

割线给出整段区间的平均变化率，区间里是否一定存在一点，让瞬时变化率恰好等于它？本片用 `f(x)=sin x` 把割线平移成切线，给出答案。

> 标题双语，整体淡入后常亮，无打字机竖线 `|`；品牌水印统一 `AIMaker-Lab`。

## 固定公式链（画面底部五行，全程位置不变）

```
k = (f(b)-f(a))/(b-a)                       ← 割线斜率 = 平均变化率
f(x) = sin x,   a = 0.28,  b = 1.46          ← 本片函数与区间
f'(x) = cos x                               ← 导函数
f'(ξ) = k  ⇒  cos ξ = (sin b - sin a)/(b-a) ← 平行条件
∃ ξ∈(a,b):  f(b)-f(a) = f'(ξ)(b-a)          ← 拉格朗日中值定理
```

本片具体取：

- `a=0.28, b=1.46`，割线斜率 `k=(sin1.46−sin0.28)/1.18≈0.608062`；
- 中值点 `ξ=arccos(k)≈0.917180`，严格落在 `(a,b)` 内；
- 切线斜率 `f'(c)=cos c` 随 `c: a→b→ξ` 连续变化，读数同步显示 `|f'(c)−k|`。

## 技术要点

- `MeanValuePlane(ImageMobject)`：静态底图（分栏、网格、a/b 标记）只渲染一次，每帧原位更新 `pixel_array`；曲线、割线、升宽三角形、滑动切线、右栏导函数与游标都画在同一 numpy 像素缓冲上。
- 虚线沿线段相对距离绘制，避免绝对坐标点积造成某些方向死循环。
- 预检验证：`cos ξ = k` 精确成立、`ξ∈(a,b)`、割线两点式一致、时间轴连续、切线与导函数游标全程落在画布内。
- 公式 PNG 由 matplotlib mathtext 预渲染（无 LaTeX）；中文标题与讲述行用微软雅黑预渲染，避免豆腐块。
- 配乐签名 **VOWELKAL-EPhrygian**（seed 271127）：E 弗里几亚 + 合唱「呜」元音垫（三声部微失谐 + F1/F2/F3 共振峰加权）+ 拇指琴金属弹片 + 框鼓轻击 + 41/8 拍 π 小数位音程序列；不循环。实测 vs 库内 19 部旧片最大 |cos| = 0.0249，自相关峰 0.134。
