# 最速降线：两点之间最快的路不是直线

`math-visualization` 的第五个动画案例（每日高等数学动画系列第 4 篇）。沿用统一视觉规范：**公式全程固定，只动参数、网格与动画**。

## 数学主线

```text
A=(0,0)，B=(6,4)，y 轴向下为正，小球无摩擦滑落，v = √(2gy)

T = ∫_A^B ds/v = ∫_0^{x_B} √(1+y'²)/√(2gy) dx        （下滑时间泛函）

L(y,y') = √(1+y'²)/√(2gy)                            （被积函数，省去常数 √2g）

L − y'·∂L/∂y' = 1/√(2y(1+y'²)) = C                   （Beltrami 恒等式）

y(1+y'²) = 2a  ⇒  x = a(θ−sinθ),  y = a(1−cosθ)      （摆线参数解）

沿摆线 T(θ) = θ√(a/g)  ⇒  T_min = θ_B√(a/g)          （摆线即最速降线）
```

数值验证：从 A 到 B，摆线 1.39 s，抛物线 1.50 s，折线 1.58 s，直线 1.63 s——摆线比直线快 14.8%。

## 画面元素与数学含义

- **顶部 3D 摆线族瀑布曲面**：深度方向是参数 `a`（从偏离值 3.8 收敛到过 B 点的 a*≈2.003）。灰色线框是整族候选摆线，青色边线是恰好穿过 B 的最优摆线，红色边线是当前候选。橙色探针球沿曲线扫描、垂线落到底面，直观呈现"调参数求极值"的过程。
- **中部 2D 竞速场**：直线（灰）、折线（橙）、抛物线（红）、摆线（青）四条轨道同场竞速，四色小球按各自真实物理时间下滑；下方四条时间条按当前时间增长，先到者条最短。
- **动态数值行**：搜寻阶段显示 `a`、`θ_B`、`x_end`、`|Δx|`（终点误差）；竞速阶段切换为 `t`、`T_cyc`、`T_line`、`Δ`（快 14.8%）。
- **底部五行公式链**全程固定；末行 `T_min = θ_B√(a/g)` 在最优解收敛后出现青色高亮下划线。
- 约 16.15 s 循环重置（标题闪烁、参数归零、竞速重来）。

## 技术栈

| 工具 | 用途 |
|------|------|
| **Manim Community 0.22** | 场景渲染、逐帧时间轴动画 |
| **matplotlib mathtext** | 无 LaTeX 环境下把公式渲染成透明 PNG |
| **Pillow** | 公式贴图、纯内存动态数字 `PixelNumber` 渲染 |
| **numpy** | 摆线求根、四轨道时间积分、小球位置插值、BGM 波形合成 |
| **ffmpeg** | H.264 编码、AAC 音轨合成 |

全程无需安装 LaTeX。

## 文件

| 文件 | 说明 |
|------|------|
| `brachistochrone_scene.py` | 最终场景：3D 摆线族曲面 + 2D 四轨竞速 + 双阶段数值行 + 固定公式链 |
| `add_bgm.py` | 合成「不循环、持续演进」的 BGM 并混入成片：缓慢滑升 pad、渐快低音心跳、不规则琶音、随收敛渐强的张力层，16.15 s 处音乐呼吸 |

`formulas/` 是公式 PNG 缓存，**无需手动准备**：脚本在图片不存在时会用 mathtext 自动生成。

## 运行

```bash
pip install -r ../../requirements.txt

# 1) 渲染（1080x1350, 30fps, ~22.3s）
manim -pqh brachistochrone_scene.py Brachistochrone

# 2) 合成背景音乐（系统需有 ffmpeg，或把 imageio-ffmpeg 的二进制放在 PATH）
python add_bgm.py media/videos/brachistochrone_scene/1350p30/Brachistochrone.mp4 output.mp4
```
