# 高斯散度定理（Divergence Theorem / Flux = Source）

场论里「边界 ↔ 内部」的第二座桥（第一座是格林公式，第三座是斯托克斯公式）：闭合曲面的净通量等于区域内部散度的体积分。

> 标题双语，整体淡入后常亮，无打字机竖线 `|`。

## 固定公式链（画面底部五行，全程位置不变）

```
∮_∂Ω F·n dS = ∭_Ω ∇·F dV                     ← 定理：边界通量 = 内部源强
F = r − p = (x−pₓ, y−p_y, z−p_z)              ← 取径向场，源点在 p
∇·F = 1+1+1 = 3                              ← 散度处处为 3
Ω = [−a,a]³:  ∭_Ω 3 dV = 24a³                 ← 体积分
Σ_faces (±a − pᵢ)(2a)² = 24a³                 ← 六个面相加，与 p 无关
```

本片具体取：

- `a` 从 0.75 增长到 1.05；终态体积分 `24 × 1.05³ = 27.783`
- 源点从 `p=(0.25,0.15,0.20)` 移动到 `p=(1.30,−0.30,0.35)`（一度移出立方体），部分面变成负通量，总和仍是 27.783
- 面通量 `qᵢ=(±a−pᵢ)(2a)²`；青条 = 流出，红条 = 流入

## 技术要点

- `DivergenceField(ImageMobject)`：静态面板底图（网格 + 坐标 + 条形图基线）预渲染一次，每帧原位更新 `pixel_array`；立方体、面着色、箭头和通量条都在同一 numpy 像素缓冲上绘制。
- 斜投影 `u = cx + 96a(x−0.56y)`、`v = cy + 96a(0.30x+0.34y−0.92z)`，三个可见面为 `+x / −y / +z`，外法向穿出箭头用投影后的法向量定方向，负通量箭头反向。
- 面元通量与体积分走独立数值路径，预检在多组 `a` 与源点（含源点在域外）下验证 `Σqᵢ = 24a³`，误差 < 1e-10。
- 公式 PNG 由 matplotlib mathtext 预渲染（`\oint` 与 `\iiint` 可用，无需 LaTeX）；按原始高度反比设定显示高度统一字号。
- 中文标签/标题用微软雅黑预渲染；公式中避免微软雅黑缺字的符号混排。标题组无光标对象。
- 配乐签名 **CHROMABOW / D-Chromatic-Square-Tape**（seed 251125）：D 半音阶 + 方波弦乐合奏（三路微失谐 + 扫频低通）+ 磁带饱和（tanh 驱动 + wow/flutter）+ 弹簧混响 + 43/8 拍分形自相似音程（1/2/4/8/4/2/1），全程不循环。
