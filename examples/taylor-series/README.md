# 泰勒展开：用多项式逼近 sin x

`math-visualization` 的第四个动画案例（每日高等数学动画系列第 3 篇）。沿用统一视觉规范：**公式全程固定，只动参数、网格与动画**。

## 数学主线

```text
sin x = x − x³/3! + x⁵/5! − x⁷/7! + ···

P_n(x) = Σ_{k=0}^{n} (−1)^k · x^(2k+1) / (2k+1)!      （截断多项式）

sin x = P_n(x) + R_n(x)                              （余项）

|R_n(x)| ≤ |x|^(2n+3) / (2n+3)!  →  0                （拉格朗日余项估计）

lim_{n→∞} P_n(x) = sin x      (∀ x ∈ ℝ)；对任意固定 x 都收敛
```

阶数 n 从 0 增加到 5，截断多项式依次是 `x`、`x − x³/6`、`… x¹¹/11!`，在 [−π, π] 上逐步贴合 sin x。

## 画面元素与数学含义

- **顶部 3D 瀑布曲面**：深度方向是阶数 n（0→5），高度是 P_n(x) 的值。灰色线框是整族多项式的"地形"，青色边线是最深处（n→∞ 极限）的 sin x，红色边线是当前阶数的 P_n(x)，随动画向青色靠拢。
- **中部 2D 收敛图**：青色 sin x 为不动目标，红色 P_n(x) 逐帧变形贴近它；橙色竖线标出各采样点的误差 |R_n(x)|。
- **青色区间条** `|R_n| ≤ 0.12`：随着 n 增大，满足误差阈值的区间从原点附近扩展到几乎整个 [−π, π]，直观展示"收敛区间在变宽"。
- **动态数值行**：`n`、`x₀`、`P_n(x₀)`、`|R_n(x₀)|` 逐帧联动；扫描点 x₀ 在 [−π, π] 上来回移动。
- 约 16.15s 循环重置（标题闪烁、阶数归零），末行 `lim P_n(x) = sin x` 在收敛后出现高亮下划线。
- 底部 5 行公式全程固定。

## 技术栈

| 工具 | 用途 |
|------|------|
| **Manim Community 0.22** | 场景渲染、逐帧时间轴动画 |
| **matplotlib mathtext** | 无 LaTeX 环境下把公式渲染成透明 PNG |
| **Pillow** | 公式贴图、纯内存动态数字 `PixelNumber` 渲染 |
| **numpy** | 泰勒多项式求值、曲面采样、收敛区间计算、BGM 波形合成 |
| **ffmpeg** | H.264 编码、AAC 音轨合成 |

全程无需安装 LaTeX。

## 文件

| 文件 | 说明 |
|------|------|
| `taylor_scene.py` | 最终场景：3D 多项式瀑布 + 2D 收敛图 + 误差区间 + 固定公式链 |
| `add_bgm.py` | 合成「不循环、持续演进」的 BGM 并混入成片：缓慢滑升的 pad、渐快低音心跳、不规则琶音、随收敛渐强的张力层，16.15s 处音乐呼吸 |

`formulas/` 是公式 PNG 缓存，**无需手动准备**：脚本在图片不存在时会用 mathtext 自动生成。

## 运行

```bash
pip install -r ../../requirements.txt

# 1) 渲染（1080x1350, 30fps, ~22.3s）
manim -pqh taylor_scene.py TaylorSeries

# 2) 合成背景音乐（系统需有 ffmpeg，或把 imageio-ffmpeg 的二进制放在 PATH）
python add_bgm.py media/videos/taylor_scene/1350p30/TaylorSeries.mp4 output.mp4
```
