# 元胞自动机：简单规则，复杂涌现

第六个案例，沿用统一视觉规范：**1080×1350 竖屏 / 30fps / 约 22s，公式全程固定，只动参数、网格与动画，暗色底 #101113，无 LaTeX**。

## 数学主线

一维初等元胞自动机：每个细胞下一时刻的状态，只由「左邻 + 自身 + 右邻」三个 0/1 决定，共有 2⁸ = 256 条规则：

```
s_i^(t+1) = f( s_(i−1)^t,  s_i^t,  s_(i+1)^t )

r = Σ_{a,b,c ∈ {0,1}} f(a,b,c) · 2^(4a+2b+c)      (Wolfram 规则编号)
```

从单个活细胞出发，四条规则长出四个世界：
- **规则 30**：看似随机的混沌三角（Wolfram 用作伪随机数发生器）
- **规则 90**：完美的谢尔宾斯基分形
- **规则 110**：复杂结构，已被证明图灵完备
- **规则 184**：车流模型，堵塞波向后传播

康威生命游戏（二维，摩尔邻域 8 格）：

```
B3/S23： 死格恰有 3 个活邻居 → 诞生
         活格有 2 或 3 个活邻居 → 存活，否则死亡
```

高斯帕滑翔机枪按此规则持续发射滑翔机——几个静止格子，凭局部规则造出会移动的"生命体"。

## 画面元素与含义

- 顶部时空图：横轴位置、纵轴世代向下；青色 = 活细胞，灰色 = 死细胞，橙色 = 当前生成的扫描行
- 规则标签 `RULE 30/90/110/184` 随演化切换，切换瞬间标题闪烁
- 中部红色网格：康威生命游戏的高斯帕枪，逐代演算（预计算 90 代循环播放）
- 数值行：`t` 世代、`rule` 规则号、`N_live` 当前行活细胞数、`gen` 生命游戏代数
- 底部 5 行固定公式链：局部规则 → 规则编号 → B3/S23 → 图灵完备 → 涌现

## 脚本说明

| 文件 | 说明 |
|------|------|
| `cellular_scene.py` | 自包含场景：CA 演化、生命游戏预计算、内存位图 `GridBitmap`、无 LaTeX 公式缓存、纯内存动态数字，逐帧时间轴驱动。 |
| `add_bgm.py` | 本片**专用**配乐「EMERGENCE / A-minimal」：A 小调五声、锯齿谐波 pad + FM 金属铃音 + 四段式粒子脉冲（对齐规则 30/90/110/184 切换点），带失谐漂移防准周期；与系列其他配乐波形相似度 < 0.01。详见 [`../../BGM_REGISTRY.md`](../../BGM_REGISTRY.md)。 |
| `formulas/` | mathtext 预渲染的公式 PNG（缺省时自动生成，无需手动准备）。 |

`GridBitmap` 用 numpy 布尔矩阵一次映射整块网格像素、原地更新 `pixel_array`，避免创建上千个 Manim 图元——这是本案例能流畅渲染 28×61 与 18×40 两张动态网格的关键。

## 运行

```bash
pip install -r ../../requirements.txt

# 1) 预览（半分辨率）
manim -pql cellular_scene.py CellularAutomata

# 2) 高清成片（1080×1350, 30fps, ~21.3s）
manim -pqh cellular_scene.py CellularAutomata

# 3) 合成不循环 BGM 并混入
python add_bgm.py
```

脚本全部使用相对路径，克隆到任意目录即可运行；`ffmpeg` 用 imageio-ffmpeg 自带二进制。
