# 案例：Dijkstra 最短路（逐跳锁定最短距离）

第七个案例，沿用统一视觉规范：**公式全程固定，只动参数、网格与动画**。

## 数学主线

```
初始化： d(s)=0,  d(v)=+∞  (v≠s)
选点：   u = argmin_{v∉S} d(v)
松弛：   d(v) ← min{ d(v), d(u)+w(u,v) }
加入：   S ← S ∪ {u}
收尾：   S=V 时 d(v) 即为最短路长度
```

只要所有边权非负，这个贪心策略就正确——它是图论"最优子结构"的经典范例。

## 画面元素

- **8 节点加权图**（手工布局，12 条无向边）：节点颜色随时间演化——灰=未访问、橙=已发现探索中（frontier）、红=当前处理节点（带脉动环）、青=已锁定最短距离
- **边色**：灰=普通、橙=正在松弛的当前边、青=最短路树的边（逐步生长）
- **距离标签**：每个节点正下方的 `d(v)` 用纯内存动态数字实时更新，未访问节点显示 `∞`
- **数值行**：`|S|`（已锁定数）、`relax`（松弛次数）、`d(H)`（终点距离）、`updates`（本步是否更新）
- **底部**：5 行固定公式链
- 约 16.15s 处快速重演算法，形成循环"呼吸"

成片终点距离 `d(H)=13`，与独立堆优化实现核验一致。
