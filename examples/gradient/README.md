# 梯度与方向导数（Gradient & Directional Derivative）

站在地形上任一点，沿某个方向走，高度变化有多快？答案是 `D_u f = ∇f · u = |∇f| cosθ`——梯度给方向，方向导数给速率，夹角 θ 决定打几折。多元微积分里最直观的一对概念。

## 固定公式链（画面底部五行，全程位置不变）

```
f(x, y)                                    ← 标量场 / 地形高度

∇f = (∂f/∂x, ∂f/∂y)                        ← 梯度：指向上升最快方向

D_u f = ∇f · u      (|u| = 1)               ← 方向导数：沿单位方向 u 的变化率

D_u f = |∇f| cos θ                          ← 与梯度的夹角决定投影

θ = 0 : max     θ = π/2 : 0     θ = π : min  ← 三种典型方向
```

本片具体取：

- 标量场 `f(x,y) = 1.10 e^{−((x−0.35)²+(y−0.25)²)/0.90} + 0.55 e^{−((x+0.75)²+(y+0.65)²)/0.70} − 0.35 e^{−((x−0.60)²+(y+0.80)²)/0.50}`（三个高斯钟形叠加，等高线清晰且梯度处处可解析求导）
- 定点 `P = (0.8, −0.2)`，`∇f(P) = (−0.6345, 1.0617)`，`|∇f| = 1.236874`
- 解析梯度用中心差分交叉校验（`|Δ| < 1e−5`），避免符号写错
- 数值联动：θ=90° 时 `D_u f = 0`（沿等高线走高度不变）；θ=180° 时 `−1.237`（逆梯度下降最快）；θ=0° 时 `+1.237`（沿梯度上升最快）

## 技术要点

- `TerrainField(ImageMobject)`：静态底图（暗青热图 + 16 层等高线 + 网格 + P 点）预计算一次，每帧复制后叠加动态层（梯度/方向箭头、角弧、直角标记、cos 条），原位更新 `pixel_array`；**每帧必须先清空为底图**，否则动态层累积成糊块。
- 等高线用 matplotlib `contour().allsegs` 一次性提取为世界坐标线段表，逐帧只做坐标映射，无实时等值线计算。
- 梯度与方向向量均以世界坐标绘制，由 `w2p()` 统一处理 y 翻转；箭头/角弧避免 PIL `arc` 的夹角方向歧义，用世界角采样成折线。
- **微软雅黑缺 `∇`(U+2207) 与 `ᵤ`(U+1D64) 字形**：含这两个符号的中文标签改为「中文 + mathtext PNG」拼接 (`Group(...).arrange(RIGHT)`)，其余 Greek/运算符可直接用雅黑渲染。
- 所有动态数值/文本都在 Timeline 持有的 Group 内，否则会被烘焙成静态层不更新。
- 配乐签名 **CONTOUR / G-Hijaz**（seed 221122）：G 阿拉伯 Hijaz 音阶 + 特雷门琴连续滑音 + 钢鼓非谐波敲击 + 磁带嘶声/抖晃 + 17/8 拍斐波那契间隔音序，全程不循环；与库内 7 部旧片最大相似度 0.0217，自身自相关峰 0.035。
