# 斯托克斯公式（Stokes' Theorem / Curl & Circulation）

闭合边界上的环流，等于任意一张以它为边界的曲面上的旋度通量——把曲面换成平圆盘，答案也不变。

## 固定公式链（画面底部五行，全程位置不变）

```
C = ∂Σ : x²+y² = R²,  z = z0                       ← 闭合边界

F = (−y, x, xy),  ∇×F = (x, −y, 2)                 ← 向量场与旋度

∮_C F·dr = ∫₀^{2π} R² dθ = 2πR²                    ← 边界环流

(∇×F)·n dS = [2 + 2h(x²−y²)/R²] dx dy              ← 曲面上的旋度通量密度

∮_∂Σ F·dr = ∬_Σ (∇×F)·n dS                         ← 斯托克斯公式
```

本片具体取：

- 边界 `C: x²+y² = 1.3², z = 0.35`，取逆时针方向
- 曲面 `Σ(h): z = 0.35 + h(1 − r²/1.69)`，先取 `h = 0.8`（抛物面帽），再连续压平到 `h = 0`（平圆盘）
- 向量场 `F = (−y, x, xy)`，`∇×F = (x, −y, 2)`
- 边界环流与曲面通量同为 `2πR² = 10.618583`；高分辨率极坐标数值积分对 `h=0.8` 与 `h=0` 都精确得到同一数值

## 技术要点

- `StokesField(ImageMobject)`：静态底图（地面投影圆）预计算一次，每帧复制后叠加动态层（线框、边界、切向箭头、旋度箭头、面元），原位更新 `pixel_array`；**每帧必须先清空为底图**。
- 3D 投影为固定视角仿射变换 `proj(x,y,z)`；曲面 `surf(h,r,θ)` 只用极坐标一个形变参数 `h`，压平时边界 `r=R` 始终不动，视觉上直接证明"同边界不同曲面"。
- 面元权重归一到精确值 `2πR²`，按极角排序形成绕边界扫过的前沿；左右两个计数在"换曲面"阶段保持不变，强化不变量叙事。
- 所有动态值/文本都在 Timeline 持有的 Group 内，否则会被烘焙成静态层不更新。
- 配乐签名 **CIRCULATE / F-Octatonic**（seed 231123）：F 八声音阶 + 克拉维键 + 管钟非谐波泛音 + 低频脉冲波 + 23/8 拍三角数间隔音序 + 双声部微复节奏漂移，全程不循环。
