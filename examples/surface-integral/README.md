# 曲面积分（Surface Integral / Flux）

向量场穿过一张曲面的通量——把曲面切成小面元，每块的贡献是 `F·n dS`，再把它们加起来。

## 固定公式链（画面底部五行，全程位置不变）

```
D = [−a,a]² ,   Σ: r(u,v) = (u, v, f(u,v))      ← 参数域与参数曲面

r_u = (1, 0, f_u) ,   r_v = (0, 1, f_v)          ← 两条切向量

r_u × r_v = (−f_u, −f_v, 1)                      ← 法向 + 面积元伸缩

F·n dS = F(r(u,v)) · (r_u × r_v) du dv           ← 单块通量贡献

Φ = ∬_Σ F·n dS = ∬_D F(r)·(r_u×r_v) du dv        ← 曲面积分 = 参数域二重积分
```

本片具体取：

- 曲面 `f(u,v) = e^(−0.45(u²+v²)) + 0.25`，参数域 `D = [−1.6, 1.6]²`
- 向量场 `F = (0.30v, 0.20u, 1.10+0.20u)`
- 通量密度 `F·(r_u×r_v) ∈ [0.895, 1.535]`（恒正，便于逐块累加）
- 数值校验：1600² 中点法算得 `Φ = 11.278093`；动画中 14×14 面元权重归一后逐块累加精确收敛到同一值

## 技术要点

- `SurfaceField(ImageMobject)`：静态底图（参数域网格 + 曲面线框 + 青色边界）预计算一次，每帧复制后叠加动态层（切向量/法向、场箭头、红色面元），原位更新 `pixel_array`；**每帧必须先清空为底图**。
- 3D 投影为固定视角的仿射变换 `proj(u,v,z)`：绕 z 轴旋转后按 TILT/ZS 压扁；线框与面元四角都用同一函数映射，避免视角错位。
- 面元权重 `w = F·(r_u×r_v) · H²` 归一到精确总通量，逐块累加无数值漂移；揭示顺序按 `u+v` 排序形成对角扫过前沿。
- 所有动态值/文本都在 Timeline 持有的 Group 内，否则会被烘焙成静态层不更新。
- 配乐签名 **FLUX / B-Locrian**（seed 2211221）：B 洛克里亚 + 玻璃琴（旋转玻璃碗拍频）+ 水琴（非谐波滑音）+ THX 深呼吸噪声 + 19/8 拍 Lucas 数间隔音序，全程不循环。
