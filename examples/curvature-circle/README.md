# 曲率与曲率圆（Curvature / Osculating Circle）

一条曲线弯得多快？把切线转角除以弧长再取极限就是曲率；取倒数得到曲率半径，画出的圆与曲线在该点二阶接触。

## 固定公式链（画面底部五行，全程位置不变）

```
κ = lim_{Δs→0} |Δα/Δs| = |dα/ds|              ← 曲率：单位弧长的转角

y = f(x):  κ = |y''| / (1 + y'²)^{3/2}         ← 图像情形的计算式

R = 1/κ = (1 + y'²)^{3/2} / |y''|              ← 曲率半径

C = (a,b) = (x − y'(1+y'²)/y'',  y + (1+y'²)/y'')   ← 圆心坐标

(x−a)² + (y−b)² = R²  ⇒  second order contact  ← 曲率圆二阶接触
```

本片具体取：

- 曲线 `f(x) = 1.2 sin x`，`f'(x) = 1.2 cos x`，`f''(x) = −1.2 sin x`
- 峰顶 `x = π/2`：`κ = 1.200`，`R = 0.833`，圆心 `(1.571, 0.367)`
- 两翼 `x = 0.85`：`κ ≈ 0.434`，`R ≈ 2.302`，圆心 `(2.279, −0.903)`
- 预检逐点验证：圆心到曲线点的距离精确等于 `R`，且圆底不越出绘图区

## 技术要点

- `CurveField(ImageMobject)`：背景网格与暗曲线预渲染一次，每帧复制后叠加按 κ 染色的曲线、切线、Δα 弧、曲率圆与半径，原位更新 `pixel_array`。
- **两轴像素比例必须一致**（`RES_W/Δx ≈ RES_H/Δy`），否则曲率圆会被拉成椭圆；通过预检扫描各采样点的 `b − R` 保证大圆不越界。
- PIL 位图内用 DejaVuSerif 直接绘制 `Δα / Δs / R=...`；中文标题与讲述行用微软雅黑 `cn_text()` 预渲染，避免豆腐块。
- 公式 PNG 由 matplotlib mathtext 预渲染，按原始高度反比设定显示高度统一字号；`lim` 与双层分式行高单独标定。
- 所有动态数值/文本都放在 Timeline 持有的 Group 内；片头两个 FadeIn 合计 1s，Timeline 内时间比成片时间晚 1s。
- 配乐签名 **REEDWALK / Bb-Lydian-dominant**（seed 241124）：Bb 吕底亚属音阶 + 双簧管哨片合成 + 低音提琴拨奏 + 纸片摩擦打击 + 29/8 随机游走音程 + 分段静默呼吸，全程不循环；vs 库内 10 部旧片最大余弦绝对值 0.0071，自身自相关 0.080。
