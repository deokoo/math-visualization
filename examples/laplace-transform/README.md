# 拉普拉斯变换（Laplace Transform / Time to Frequency）

把时间函数乘以衰减核 `e^(-st)` 再对 `t≥0` 积分，就得到复频域函数 `F(s)`；收敛域由极点决定。

> 本片起：**标题不再显示打字机竖线 `|`**，标题整体淡入后保持常亮。

## 固定公式链（画面底部五行，全程位置不变）

```
F(s) = L{f(t)} = ∫₀^∞ f(t) e^(-st) dt          ← 定义：时间 → 复频域

f(t) = e^(-at)  ⇒  f(t)e^(-st) = e^(-(s+a)t)   ← 指数函数的乘积

∫₀^T e^(-(s+a)t) dt = [1 - e^(-(s+a)T)] / (s+a) ← 有限上限的积分

T → ∞, s+a > 0:  F(s) = 1 / (s+a)              ← 收敛时的闭式结果

ROC: Re(s) > -a   (pole s = -a)                ← 收敛域与极点
```

本片具体取：

- `a = 0.8`，`f(t) = e^(-0.8t)`，取实数 `s = σ`
- `σ = 1.2` 时 `F(s) = 1/(2.0) = 0.500`；积分上限扫到 `T = 6` 时部分积分 `F_T = 0.499997`
- `σ` 穿过 `-a = -0.8` 时，乘积不再衰减、面积发散，右侧收敛域阴影随之失效

## 技术要点

- `LaplaceField(ImageMobject)`：静态双面板底图（时间域网格 + s 实轴）预渲染一次，每帧原位更新 `pixel_array`，叠加 f(t)、核、乘积面积与 ROC 阴影。
- 数值路径与闭式解一致：`F_T = (1 − e^(-(s+a)T))/(s+a)`；预检对多个 `σ` 验证 `T=60` 时与 `1/(s+a)` 误差 < 1e-6。
- `s+a ≤ 0` 时数值改为显示 `∞`，并在 s 平面标红 `DIVERGES`，避免误把发散面积当成结果。
- 公式 PNG 由 matplotlib mathtext 预渲染；`\mathcal{L}` 会触发 STIX 符号替换，属正常提示。按原始高度反比设定显示高度统一字号。
- 标题组不含光标对象，也不再执行闪烁逻辑；片头仅用一次 `FadeIn(title)`。
- 配乐签名 **CHORALIN / Ab-Major-Blues**（seed 2411243）：Ab 大调布鲁斯 + 低音单簧管 + 钟琴槌击 + 合唱元音合成 + 37/8 倒计数间隔 + 变速静默呼吸，全程不循环。刻意避开了同期作品的「手风琴 + 吉他泛音 + 陶笛 + 31/8 质数间隔」组合；与库内 12 部旧片最大余弦绝对值 0.0295，自相关 0.363。
