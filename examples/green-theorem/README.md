# 格林公式（Green's Theorem）

沿闭合曲线绕一圈的环流，等于这片区域内部旋度之和——多元微积分里「边界 ↔ 区域」的经典桥梁。

## 固定公式链（画面底部五行，全程位置不变）

```
C = ∂D  （正向 / 逆时针）

F = (P, Q) ,   ∮_C P dx + Q dy                    ← 沿边界的环流

∂Q/∂x − ∂P/∂y = (∇ × F) · k                       ← 旋度密度

∬_D (∂Q/∂x − ∂P/∂y) dA                            ← 区域内旋度之和

∮_C P dx + Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dA          ← 格林公式
```

本片具体取：

- 区域边界 `C: r(θ) = 1.28 + 0.16 sin3θ + 0.09 cos5θ`（逆时针，面积 ≈ 5.2001）
- 向量场 `F = (P, Q) = (−y + 0.35xy, x + 0.25xy)`
- 旋度 `∂Q/∂x − ∂P/∂y = 2 − 0.35x + 0.25y`（恒正，全音阶红色热图深浅对应其大小）
- 数值校验：`∮_C Pdx+Qdy = 10.400870`，`∬_D curl dA = 10.400870`（用 4001 点边界梯形法 + 46 格面积权重归一，逐格累积精确收敛到同一值）
- 特例（文稿中提及）：`F = (−y, x)` 时旋度恒为 2，`∮ x dy − y dx = 2·Area(D)`

## 技术要点

- `GreenField(ImageMobject)`：静态底图（网格 / 区域填充 / 向量场 / 边界）预计算一次，每帧复制后叠加动态层（小格、抵消标记、热图、轨迹），原位更新 `pixel_array`；**每帧必须先清空为底图**，否则动态层累积成糊块。
- 热图先画在独立 RGBA 层，再用 `REGION_MASK` 灰度蒙版贴回，严格贴合曲线 C，消除方格边界的矩形缺口。
- 边界环流预计算 4001 点累积数组，逐帧只查表插值，避免实时积分；面积分用 46 格权重归一保证与边界积分精确相等。
- 所有动态数值 / 文本都在 Timeline 持有的 Group 内，否则会被烘焙成静态层不更新。
- 配乐签名 **VORTEX / C#-WholeTone**（seed 211121）：C# 全音阶 + formant 人声共振 pad + 簧片风琴 + 金属板非谐波共振 + 13/8 拍素数间隔音序，全程不循环。
