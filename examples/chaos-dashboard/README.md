# 混沌与动力系统 · 八面板现场求解

八个经典非线性/混沌系统并行演化的仪表盘：1080×1350 竖屏、30fps、70 秒、暗色底、公式全程固定只动参数与轨迹。是「七个偏微分方程」仪表盘的姊妹篇，但主题换成动力系统。所有轨迹由 numpy 数值积分现场生成，无预渲染路径、无 LaTeX。

## 技术要点

- **无 Manim、无 LaTeX**：逐帧 numpy 求解 + PIL 绘制，经 ffmpeg rawvideo 管道直接编码 H.264。公式用 matplotlib mathtext 预渲染成透明 PNG（`formulas/`），首次运行自动生成。
- **数值稳定**：洛伦兹/罗斯勒/双摆/范德波尔/杜芬全部 RK4 定步长；双摆角度是 unwrapped 的（会转成百弧度量级），作图只用 sin/cos，预检据此校验有界性。
- **曼德博配色坑**：初版用全局 `linspace(−2.2,0.8)` 的低分辨率数组直接裁剪，zoom 中心坐标错位落到集合内部，整块糊成纯色。改为对海马谷 `c∈[−0.90,−0.64]×[0.02,0.22]` 单独做 520×420 / 220 次迭代的 numpy 向量化预计算，配合 `sqrt(k/maxiter)` 对数色阶，边界螺旋全程清晰。
- **洛伦兹比例坑**：归一化后投影跨度约 ±11（y）/±8（x），比例系数取 `min(panelW/30, panelH/40)` 才能占满面板又不出界。
- **画幅**：全系列统一 1080×1350（4:5）竖屏。编码 H.264 yuv420p + AAC。

## 配乐

签名 **COLLAGE-CSharpSync**（seed 2711277）：C# 自然小调（C#3=138.59Hz）+ 同步锯齿波（sync-saw，失谐三路 + 低速滤波扫频）+ 环形调制铃（载波×非公度比 1.4142/1.618 调制）+ 反向磁带拼贴片段（带 wow/flutter 抖晃）+ 非节拍游走事件流；全程不循环、持续演进。与库内旧片最大余弦相似度实测 < 0.1，自相关峰 < 0.8。

## 运行

```bash

```
