# 七个偏微分方程 · 现场求解（PDE Dashboard）

复刻自一段展示七个偏微分方程实时求解的多面板可视化。与本系列其他竖屏动画不同，本案是 **720×1600（9:20）**、**70 秒**、**八面板仪表盘**；八个画面全部由 numpy 数值求解 + PIL 逐帧绘制，无预渲染路径、无 LaTeX。

## 公式链（每块面板顶部固定，只动下方数值解）

| 面板 | 方程 | 数值方法 |
|------|------|----------|
| 热传导 | `∂u/∂t = α∇²u` | 二维显式差分，两个高斯热源扩散 |
| 波动 | `∂²u/∂t² = c²∇²u` | d'Alembert 解析解，脉冲分裂成左右行波（三条泳道：左行/右行/合成） |
| 麦克斯韦 | `∇×E = −∂B/∂t`，`∇·B=0` | 振荡偶极辐射场线 |
| 纳维-斯托克斯 | `ρ(∂ₜu+u·∇u)=−∇p+μ∇²u`，`∇·u=0` | 圆柱绕流势流 + 交替涡脱落粒子 |
| 薛定谔 | `iℏ∂ₜψ = −(ℏ²/2m)∇²ψ` | 高斯波包的三维线框曲面 |
| 波函数模方 | `|ψ|² / ∫|ψ|²dx = 1` | 振荡波 + 归一化高斯包络 |
| 梁振动 | `∂ₜ²u + (EI/ρA)∂ₓ⁴u = 0` | 悬臂梁一阶模态线框 |
| 反应扩散 | `∂ₜu = Dᵤ∇²u − uv² + F(1−u)` | Gray–Scott 模型，斑图自组织 |

## 视觉与技术要点

- **双语标题**：中文「偏微分方程 · 现场求解」+ 英文 `PDE · SEVEN EQUATIONS IN MOTION`，全程常亮、无打字机光标；右上水印 `AIMaker-Lab`。
- **公式 PNG**：`matplotlib.mathtext` 在**无 LaTeX** 环境渲染成透明底 PNG；主/副公式分别缓存到 `formulas/*.png`、`*_sub.png`，不存在时自动生成。
- **中文字幕**：微软雅黑 `C:/Windows/Fonts/msyh.ttc` 预渲染，10 段解说逐段切换，底部带进度条。
- **纯数值动画**：热传导、Gray–Scott 用显式差分逐步推进；该脚本不依赖 Manim，`python pde_scene.py` 直接逐帧绘制并经 ffmpeg 管道编码。
- **配乐** LYDIAN-GlassLab（seed 271127）：G 利底亚（含 ♯4=C♯）+ 模拟合成器弦乐 pad（三路失谐锯齿扫频）+ 铁琴非谐波泛音 + 低频脉冲 + 41/8 拍平方数间隔，持续演进不循环。实测 vs 库内全部旧片最大 |cos| = 0.0269，整段自相关峰 0.0634。

## 运行

```bash
python pde_scene.py --preview          # 21 张低分辨率关键帧，检查布局
python pde_scene.py                    # 渲染 720x1600 / 30fps / 70s 无声成片
python add_bgm.py 70.0                 # 合成配乐、校验差异化、混入得到 pde_final.mp4
```

输出 `pde_final.mp4`。公式 PNG 缓存目录 `formulas/` 无需手动准备，脚本会自动生成；全部使用相对路径。
