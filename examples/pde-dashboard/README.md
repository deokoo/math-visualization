## 公式链（每块面板顶部固定，只动下方数值解）

| 面板 | 方程 | 数值方法 / 画法 |
|------|------|----------|
| 热传导 | `∂u/∂t = α∇²u` | 二维显式差分，两个高斯热源扩散；蓝底热图 + 右侧色条 |
| 波动 | `∂²u/∂t² = c²∇²u` | d'Alembert 解析解；三条泳道（右行金 / 左行蓝 / 合成白），两端固定壁 + 行进箭头 |
| 麦克斯韦 | `∇×E = −∂B/∂t`，`∇·B=0` | 电偶极场线 `r = r₀cos²θ`，左右对称环绕红/蓝偶极中心 |
| 纳维-斯托克斯 | `ρ(∂ₜu+u·∇u)=−∇p+μ∇²u`，`∇·u=0` | 绕流速度场 + 弯曲流线网格 + 翼型 + 示踪粒子 |
| 薛定谔 | `iℏ∂ₜψ = −(ℏ²/2m)∇²ψ` | 高斯波包 `Re ψ` 3D 曲面，圆形视口内旋转，颜色随高度蓝→紫红 |
| 波函数模方 | `|ψ|² / ∫|ψ|²dx = 1` | 窄高斯包络 × 高频振荡的金色尖波包 + 基线 |
| 梁振动 | `∂ₜ²u + (EI/ρA)∂ₓ⁴u = 0` | 悬臂梁一阶模态：3D 实体梁 + 网格纹理 + 残影摆动 + 固定墙 |
| 反应扩散 | `∂ₜu = Dᵤ∇²u − uv² + F(1−u)` | Gray–Scott 模型，橙红热图自组织斑图 |
